# DESIGN — 최종 디자인 기준 R3 (2026-11-13)

`prototype-index.html`(1분 체험)과 `prototype-dashboard.html`(발표 화면)이 기준 시안이다. 화면 구성·문구·상호작용·아이콘·캐릭터는 이 두 파일을 그대로 따르고, SPEC.md의 구조(파일 분리, Apps Script 연결, 오프라인 대체)로 옮긴다. 시연 페이지: https://claude.ai/artifact/TnS2GotrDngfP7bC2CC3fz

## 방향: 세종청년센터 디자인 언어를 우리 브랜드로
센터 누리집(4242.or.kr)에서 가져온 요소: 청록 CI 계열, 보라·하늘·노랑·코랄 포인트, 둥글고 굵은 제목 글꼴, 반짝이(네 갈래 별)·구름 모티프, 진한 테두리 + 그림자를 댄 스티커 카드, 점 눈 얼굴 캐릭터 느낌. "청년과 사이를 연결합니다", CI의 '다리' 의미가 우리 '연결' 메시지와 맞는다.
- 센터 로고·기존 캐릭터·공식 표식은 쓰지 않는다. 캐릭터 '고미'(구름)와 아이콘은 직접 그린 SVG다(`prototype-index.html`의 ART 스크립트).
- 기관 이름에는 '협력 미확인'을 붙인다.

## 글꼴
- 제목·숫자: Jua (Google Fonts)
- 본문: Noto Sans KR 400/500/700/800 (Pretendard를 저장소에 포함할 수 있으면 교체 가능)
- 최소 글자 13px

## 구성 요소
- 스티커 카드: 테두리 2px #22252B, 모서리 16~22px, 그림자 4px 4px 0 #22252B
- 주요 버튼: 높이 58px 이상, 청록 바탕, 노랑 그림자 + 테두리, 누르면 그림자 쪽으로 눌림
- 선택지 타일: 아이콘 상자(46px) + 이름, 선택 시 민트 바탕 + 체크 배지, 0.22초 뒤 다음 질문
- 진행 표시: 점선 길 위를 고미가 이동, 오른쪽에 n / 4
- 이전 답 칩: 높이 44px, 누르면 그 질문으로
- 결과: 점수 링(96px) + 유형 배지 + 제목 → 단서 해시태그 → 학생 팀 카드(전공 아바타, 할 일 체크) → 기관 카드(협력 미확인) → 담당자 확인 문구
- 가게 이름(선택): 결과 화면 맨 아래 노란 스티커 카드, 상점 아이콘 + "선택" 배지, 입력칸 높이 52px·글자 17px, 체크 아이콘 안내문. 제출 후 잠금
- 완료: 청록 전체 화면, 반짝이, 위쪽 화살표, 놀란 고미, "앞 화면을 보세요!"

## 새 고민 알림 (11/14)
- 말풍선: 흰 스티커(노랑 그림자), 꼬리는 왼쪽 아래, 19px 굵게, 강조 단어 청록. 1280px 화면에서는 오른쪽 버튼을 피해 줄바꿈. 휴대폰은 화면 위 고정 토스트
- 반짝: 노랑 4px + 진한 2px 테두리 링, '+n' 노란 알약(Jua 18px), 0.55초 튀어나오는 애니메이션(동작 줄이기 설정이면 끔)
- 종: 52px 흰 스티커 버튼, 열리면 노랑. 배지 코랄 #C9472A + 흰 숫자
- 알림함: 420px 스티커 카드 + 위쪽 꼬리, 탭·버튼 높이 44px, 업종 아이콘 상자 44px, 목록 최대 높이 넘으면 안에서 스크롤

## 측정 기준 (배포 전 다시 확인)
- 두 시나리오 완주(탭 6~7회), 대비 4.5:1 이상(측정 최저 4.75:1), 터치 44px 이상, 글자 13px 이상, 폭 390px 가로 넘침 없음
- 휴대폰 제출 → 대시보드 반영 3초 이내
- 실제 글꼴(Jua) 적용 화면은 배포 후 휴대폰에서 다시 확인
